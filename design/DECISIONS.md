## Out of scope (confirmed)

- **Spacing and elevation scales:** the code has none beyond Tailwind's defaults and an ad hoc
  `shadow-sm`/`shadow-xl`/`shadow-2xl`. Not invented in the kit; shadows are drawn as per-component
  effects.
- **Motion tokens:** the code has one (`--duration-brand-feedback: 120ms`) and unrelated Tailwind
  durations (`duration-200`, `duration-300`). The token is a kit gap (G3); the missing vocabulary is
  a `ui-motion` decision.
